# Contributors

Recomp Studio is built in the open by people and tools that improve its
analysis, runtime, verification, documentation, and evidence workflows.

## Codex

**Codex (OpenAI coding agent)** — implementation, runtime debugging,
differential-test investigation, application-corpus validation, and project
documentation.

Codex changes are reviewed and committed under the repository maintainer's
GitHub identity, with signed commits identifying the work in the commit
history.
