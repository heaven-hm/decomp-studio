# PE32-to-macOS MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a tested CLI that statically recompiles supported subsets of genuine PE32 x86 and PE32+ x64 machine code into runnable native macOS ARM64 host executables.

**Architecture:** A dependency-free C++20 core parses PE32/PE32+ and decodes/lifts minimal IA-32 and AMD64 subsets into canonical JSON IR. A deterministic C++ generator and portable runtime produce a CMake host project; the CLI records analysis and differential-verification evidence.

**Tech Stack:** C++20, CMake, Ninja, Apple Clang, CTest, Python 3 fixture builder.

## Global Constraints

- Input is actual PE32/PE32+ machine code; generated fixtures are binary files, never substituted source.
- Unsupported behavior returns structured diagnostics and a non-zero exit status.
- macOS ARM64 is the only executable target claimed supported in this plan.
- Each increment must build, pass tests, and be committed independently.
- No upstream code is copied; research provenance is documented.
